## 3. มาตรฐานร่วมของทุกหน้า

### 3.1 หน้าตาและโครง (ยึดตาม `week02-infographic.html`)
- ธีมมืด สีหลักม่วง `#8b7cf8` ไล่เฉด `#6f9bff → #8b7cf8 → #b38cf5` พื้น `#141518` การ์ด `#1f2024` เส้น `#35363c`
- ฟอนต์: Prompt (หัวเรื่อง ตัวเลข) + Noto Sans Thai (เนื้อหา) จาก Google Fonts
- โครงหน้า: แถบบนติดจอ (ชื่อวิชา + เมนูหัวข้อ; บนมือถือเป็นปุ่ม ☰ สารบัญ), แถบความคืบหน้า, ปุ่ม "ถัดไป" มุมขวาล่าง, แต่ละหัวข้อเป็น `<section class="sec" id="..." data-nav="...">`
- คีย์บอร์ด: `→` `Space` `PageDown` ไปหัวข้อถัดไป, `←` `PageUp` ย้อน (ไม่ทำงานเมื่อโฟกัสอยู่ใน input)
- องค์ประกอบที่มีอยู่แล้วและควรใช้ซ้ำ: ป้าย "ลองเล่น" (`.try`), กล่องเคล็ดลับ (`.tip`), ปุ่มสลับ (`.switch`), การ์ดพลิก (`.flip`), เช็กลิสต์ติ๊กได้ (`.chk`), แถบเกณฑ์คะแนน (`.rub`), แอนิเมชันเผยตัวเมื่อเลื่อนถึง (`.rv`)

### 3.2 เนื้อหา
- ภาษาไทย ศัพท์เทคนิคใช้อังกฤษ น้ำเสียงเป็นกันเอง ประโยคสั้น
- **ทุกหัวข้อต้องมีอย่างน้อย 1 อย่างให้ กด ลาก หรือปรับ** ถ้าหัวข้อไหนมีแค่ข้อความ ให้รวมกับหัวข้ออื่น
- ตัวเลขตัวอย่างทุกชุดต้องกำกับว่า "ข้อมูลสมมติเพื่อการสอน"
- รายละเอียดงาน เกณฑ์คะแนน และข้อกำหนดไฟล์ ที่ไม่ได้มาจาก syllabus ให้กำกับว่า "ตัวอย่าง ปรับได้ตามผู้สอน"
- ตอนท้ายทุกหน้า: งานประจำสัปดาห์ + เช็กลิสต์ก่อนส่ง + บรรทัด "สัปดาห์หน้า → ..."
- ตอนต้นทุกหน้า (ยกเว้นสัปดาห์ 1): แถบสั้น ๆ "ต่อจากสัปดาห์ก่อน" บอกว่าใช้อะไรจากงานเดิม

### 3.3 เทคนิค
- ไฟล์ HTML เปิดได้เลย ไม่มีขั้นตอน build ไม่มี framework
- JS ธรรมดา ภาพประกอบเป็น SVG หรือ Canvas ที่วาดด้วยโค้ด ไม่ใช้ไฟล์ภาพจากภายนอก
- ไลบรารีภายนอก: ใช้เท่าที่จำเป็นจริง ๆ ถ้าต้องใช้ ให้ vendor ไว้ใน repo พร้อม SRI ตามแนวทางที่ repo ใช้กับ SheetJS
- Responsive: ต้องใช้ได้ที่ความกว้าง 360–430 px โดยไม่มีการเลื่อนแนวนอนของทั้งหน้า ตัวอักษรเนื้อหาไม่เล็กกว่า 15 px ปุ่มสูงไม่น้อยกว่า 40 px
- ส่วนที่ลากได้ต้องใช้ Pointer Events (ใช้ได้ทั้งเมาส์และนิ้ว) และตั้ง `touch-action` ไม่ให้แย่งการเลื่อนหน้า
- ค่าที่นักศึกษาปรับไว้ เก็บใน `localStorage` ได้ (ห่อด้วย try/catch) ใช้ key ขึ้นต้น `artd2303.`
- เคารพ `prefers-reduced-motion`: ลดหรือปิดแอนิเมชันอัตโนมัติ

## 5. แกนเรื่องต่อเนื่องทั้งเทอม

syllabus ออกแบบให้งานสัปดาห์ 2–5 รวมกันเป็นงานกลางภาค (Motion Infographic 30–60 วินาที ที่มีตัวละครที่ออกแบบเอง) สื่อการสอนจึงควรใช้ **ตัวอย่างเดียวกันต่อเนื่อง** ให้นักศึกษาเห็นว่างานแต่ละสัปดาห์ต่อกันยังไง

- **ข้อมูลตัวอย่าง:** ชุดเดียวกับสัปดาห์ 2 — "นักศึกษา 7 ใน 10 คนเรียนผ่านมือถือ" (มือถือ 68 · โน้ตบุ๊ก 24 · แท็บเล็ต 8, ข้อมูลสมมติ)
- **ตัวละครตัวอย่าง:** ตัวละครที่นักศึกษาสร้างจากตัวสุ่มคอนเซปต์ในสัปดาห์ 3 (ฐาน + บุคลิก + ธีม) เก็บใน `localStorage` key `artd2303.character` สัปดาห์ 4, 5, 8, 10 อ่านค่านี้มาแสดงเป็นตัวละครเดียวกัน ถ้าไม่มีค่า ใช้ค่าเริ่มต้น
- **ครึ่งหลัง (สัปดาห์ 7–12):** ใช้โจทย์ตัวอย่างชุดใหม่ 1 ชุดตลอด เช่น แคมเปญรณรงค์ของชมรมสมมติ ตั้งชื่อเป็นแบรนด์สมมติให้ชัดว่าไม่มีอยู่จริง

## 6. รายละเอียดรายสัปดาห์

หัวข้อและรายละเอียดคัดจาก syllabus ส่วน interactive คือสิ่งที่ต้องสร้าง จำนวนหัวข้อย่อยต่อหน้าประมาณ 8–14 หัวข้อ

### สัปดาห์ 1 · แนะนำรายวิชา · หลักการออกแบบกราฟิก 2 มิติ
**syllabus:** ภาพเวกเตอร์และบิตแมป ขนาด ความละเอียด และโหมดสีสำหรับสื่อสิ่งพิมพ์และสื่อออนไลน์ · ปูพื้นโปรแกรมกราฟิก · ชี้แจงโปรเจกต์กลางภาคและปลายภาค

Interactive:
1. **เวกเตอร์ vs บิตแมป:** รูปเดียวกันสองแบบวางคู่กัน มีแถบซูม 1×–16× ฝั่งบิตแมปแตกเป็นพิกเซล ฝั่งเวกเตอร์คมเท่าเดิม
2. **เครื่องคำนวณขนาดและความละเอียด:** กรอกขนาดพิกเซล + PPI → ขนาดพิมพ์เป็นซม. และกลับกัน มีปุ่มค่าสำเร็จรูป (A4/A3 ที่ 300 PPI, โพสต์ 1080×1350, วิดีโอ 1920×1080)
3. **RGB vs CMYK:** วงกลมสีซ้อนกัน 3 วง ลากได้ สลับโหมดผสมแบบบวก (แสง) กับแบบลบ (หมึก) พร้อมคำอธิบายว่าทำไมสีบนจอสดกว่างานพิมพ์
4. **เลือกชนิดไฟล์:** โจทย์งาน 6 ข้อ (โลโก้, ภาพถ่ายลงเว็บ, โปสเตอร์ส่งโรงพิมพ์, ไอคอนพื้นใส ฯลฯ) ให้เลือก SVG / PNG / JPG / PDF แล้วเฉลยพร้อมเหตุผล
5. **แผนที่รายวิชา:** ไทม์ไลน์ 12 สัปดาห์ กดแต่ละสัปดาห์เห็นหัวข้อและชิ้นงาน เห็นว่าสัปดาห์ 2–5 รวมเป็นงานกลางภาค และ 7–11 เป็นงานปลายภาค
6. **การ์ดโปรเจกต์:** กลางภาค (Motion Infographic 30–60 วินาที) และปลายภาค (แอนิเมชัน/โมชันกราฟิก 2 มิติ 1–2 นาที พร้อมสื่อประชาสัมพันธ์)

งาน: ไม่มีชิ้นงานใหญ่ ใช้เช็กลิสต์ "พร้อมเรียน" (ติดตั้งโปรแกรม, ตั้งค่าไฟล์ใหม่ถูกโหมดสี, บันทึกไฟล์ต้นฉบับ)

### สัปดาห์ 3 · Character Design
**syllabus:** รูปทรง สัดส่วน สี และบุคลิกของตัวละคร · ร่างแบบหลายแบบ เลือกแบบ แล้วทำ turnaround และ expression sheet

ใช้ `character.js` ที่ดึงจาก `arttoy-w02-03-2d.html` (ตัวสุ่มคอนเซปต์, shape language รวมสามเหลี่ยมกลับหัว, สัดส่วน, เงาดำ, ชุดสี, turnaround) โดยตัดเนื้อหาเรื่องการผลิตอาร์ตทอยและ 3D ออก แล้วเพิ่ม:
1. **ร่างหลายแบบ แล้วเลือก:** แสดงตัวละคร 6 แบบจากคอนเซปต์เดียวกัน (สุ่มรูปทรง สัดส่วน ชุดสี) กดเลือก 1 แบบเป็นตัวหลัก มีปุ่มสุ่มใหม่
2. **Expression sheet:** ตาราง 6 ช่อง ตัวละครเดียวกัน 6 อารมณ์ (ปกติ ดีใจ เศร้า โกรธ ตกใจ ง่วง) กดแต่ละช่องดูว่าคิ้ว ตา ปาก เปลี่ยนอย่างไร
3. **ทดสอบความคงเส้นคงวา:** ปุ่มเปิดเส้นไกด์บน turnaround และโหมด "แบบผิด" (มีอยู่แล้วในต้นฉบับ)
4. เชื่อมกับสัปดาห์ 2: การ์ดโปรไฟล์ตัวละคร (ชื่อ บุคลิก สิ่งที่ชอบ) เป็นอินโฟกราฟิกอย่างหนึ่ง

บันทึกตัวละครที่เลือกลง `localStorage` ตามหัวข้อ 5
งาน: character sheet 1 ตัว (ร่าง 3 แบบ, ตัวที่เลือก, turnaround หน้า·ข้าง·หลัง, expression อย่างน้อย 4 อารมณ์, ชุดสี)

### สัปดาห์ 4 · Storyboard
**syllabus:** การเล่าเรื่องด้วยภาพ ขนาดภาพ มุมกล้อง และการเปลี่ยนฉาก · จาก thumbnail สู่ storyboard ของงานกลางภาค

Interactive:
1. **ขนาดภาพ:** ฉากเดียวมีตัวละคร แถบเลื่อน ELS → LS → MS → CU → ECU กรอบภาพครอปตาม พร้อมบอกว่าแต่ละขนาดใช้เล่าอะไร
2. **มุมกล้อง:** สลับ ระดับสายตา / มุมสูง / มุมต่ำ / มุมเอียง ตัวละครและเส้นขอบฟ้าเปลี่ยนตาม พร้อมความรู้สึกที่ได้
3. **กฎ 180 องศา:** มุมมองจากด้านบน ตัวละคร 2 ตัว ลากกล้องได้ แสดงภาพที่กล้องเห็น เมื่อข้ามเส้นจะเตือนว่าตัวละครสลับฝั่ง
4. **การเปลี่ยนฉาก:** ตัวอย่าง cut, dissolve, wipe, match cut เล่นด้วย CSS animation กดเล่นซ้ำได้
5. **ตัวสร้าง storyboard:** ช่องภาพ 6–8 ช่อง แต่ละช่องเลือกขนาดภาพ มุมกล้อง ใส่คำอธิบายและจำนวนวินาที ลากสลับลำดับได้ มีผลรวมเวลา และเตือนถ้าไม่อยู่ใน 30–60 วินาที
6. **จาก thumbnail สู่ storyboard:** ตัวอย่าง 3 ขั้น (ร่างหยาบ → จัดองค์ประกอบ → ใส่ลูกศรการเคลื่อนไหวและโน้ต) ใช้เรื่อง "7 ใน 10 คนเรียนผ่านมือถือ"

งาน: storyboard ของงานกลางภาค 8–12 ช่อง พร้อมเวลาต่อช็อต

### สัปดาห์ 5 · Motion Graphic เบื้องต้น
**syllabus:** หลักการแอนิเมชัน (timing, spacing, easing) และ keyframe · ทำให้ตัวอักษร รูปทรง ไอคอน และตัวละครเคลื่อนไหว · เริ่มผลิตงานกลางภาค

Interactive:
1. **Timing vs Spacing:** ลูกบอลวิ่งระยะเท่ากัน ปรับจำนวนเฟรม (timing) และการกระจายตำแหน่ง (spacing) แสดงเงาตำแหน่งทุกเฟรมแบบ onion skin
2. **สนามเด็กเล่น Easing:** กราฟ cubic-bezier ลากจุดควบคุมได้ มีปุ่มค่าสำเร็จรูป (linear, ease-in, ease-out, ease-in-out, overshoot) เทียบการเคลื่อนไหว 2 แบบพร้อมกัน
3. **Keyframe เบื้องต้น:** ไทม์ไลน์เล็ก ๆ มี 3 คีย์เฟรม ปรับตำแหน่ง ขนาด ความทึบ แล้วกดเล่น
4. **เฟรมเรต:** แอนิเมชันเดียวกันที่ 8 / 12 / 24 / 60 fps วางคู่กัน
5. **หลักแอนิเมชันที่ใช้บ่อย:** เปิดปิด squash & stretch, anticipation, follow-through, overshoot บนวัตถุเดียวกัน
6. **ตัวอย่าง 4 ประเภท:** ตัวอักษร (kinetic text), รูปทรง, ไอคอนจากสัปดาห์ 2 (กราฟแท่งค่อย ๆ ขึ้น), ตัวละครจากสัปดาห์ 3 (กะพริบตา โบกมือ เด้งเข้าฉาก)

งาน: ทดลองเคลื่อนไหว 3 ชิ้นสั้น ๆ (ตัวอักษร ไอคอน ตัวละคร) และเริ่มผลิตงานกลางภาค

### สัปดาห์ 6 · Midterm Project: Motion Infographic
**syllabus:** ส่งและนำเสนอโมชันอินโฟกราฟิก 30–60 วินาที ที่มีตัวละครที่ออกแบบเอง (รวมงาน Infographic, Character Design, Storyboard และ Motion Graphic) · วิพากษ์ผลงาน

หน้านี้เป็นหน้าช่วยส่งงานและนำเสนอ ไม่ใช่บทเรียนใหม่:
1. **สรุปโจทย์:** ภาพรวมว่า 4 สัปดาห์ที่ผ่านมาประกอบเป็นงานนี้อย่างไร
2. **ข้อกำหนดไฟล์:** การ์ดสเปก (ความยาว, ขนาดภาพ, เฟรมเรต, ชนิดไฟล์) กำกับว่าเป็นตัวอย่าง
3. **เช็กลิสต์ก่อนส่ง:** แบ่ง 4 หมวดตามที่มา (ข้อมูล, ตัวละคร, การเล่าเรื่อง, การเคลื่อนไหว) มีแถบความคืบหน้ารวม
4. **ประเมินตัวเอง:** แถบเลื่อนให้คะแนนตามเกณฑ์แต่ละข้อ รวมคะแนนอัตโนมัติ (เกณฑ์เป็นตัวอย่าง)
5. **ตัวจับเวลานำเสนอ:** ตั้งเวลาได้ มีสัญญาณเตือนเมื่อใกล้หมด
6. **กรอบการวิพากษ์:** การ์ด "ฉันชอบ… / ฉันอยากให้… / ถ้าลอง…" พิมพ์โน้ตได้ เก็บในเครื่อง มีปุ่มคัดลอกข้อความ

### สัปดาห์ 7 · เปิดโจทย์ Final Project
**syllabus:** โจทย์: แอนิเมชัน/โมชันกราฟิก 2 มิติ 1–2 นาที สื่อสารประเด็นหรือแบรนด์ พร้อมสื่อประชาสัมพันธ์ · สรุปจุดพัฒนาจากงานกลางภาค · ค้นคว้าตัวอย่างและทำ mood board

Interactive:
1. **การ์ดโจทย์:** สิ่งที่ต้องส่งทั้งหมด (วิดีโอ, โปสเตอร์หรือ key visual, ไฟล์ต้นฉบับ)
2. **ตัวช่วยตั้งหัวข้อ:** เลือก ประเด็นหรือแบรนด์ × กลุ่มเป้าหมาย × น้ำเสียง → ได้ประโยคโจทย์ 1 ประโยค มีปุ่มสุ่ม
3. **ทบทวนงานกลางภาค:** ช่อง "เก็บไว้ / ปรับปรุง / ลองใหม่" พิมพ์ได้ เก็บในเครื่อง
4. **Mood board 5 ช่อง:** สไตล์ภาพ, สี, ตัวอักษร, การเคลื่อนไหว, เสียง กดดูว่าแต่ละช่องควรใส่อะไร
5. **แผนงาน 6 สัปดาห์:** ไทม์ไลน์สัปดาห์ 7–12 พร้อมจุดตรวจความคืบหน้าครั้งที่ 1 (สัปดาห์ 9) และครั้งที่ 2 (สัปดาห์ 11) ติ๊กงานที่เสร็จได้

งาน: ประโยคโจทย์ + mood board 1 หน้า

### สัปดาห์ 8 · พัฒนาแนวคิดและตัวละคร
**syllabus:** เขียนบท (script) · ต่อยอดตัวละครให้พร้อมเคลื่อนไหว (แยกชิ้นส่วน ท่าทาง สีหน้า) · กำหนด style frame สี และตัวอักษรของงาน

Interactive:
1. **แม่แบบบท 2 คอลัมน์:** ภาพ / เสียง พิมพ์ได้ทีละแถว นับคำและประมาณความยาวเป็นวินาที เตือนถ้าไม่อยู่ใน 1–2 นาที (บอกว่าเป็นค่าประมาณ)
2. **แยกชิ้นส่วนตัวละคร:** ตัวละครจากสัปดาห์ 3 กดปุ่มกางชิ้นส่วน เห็นเลเยอร์ (หัว ลำตัว แขนบน แขนล่าง ขา) และจุดหมุนของแต่ละชิ้น
3. **จุดหมุนสำคัญอย่างไร:** ลากจุดหมุนของแขน แล้วหมุนดู จุดหมุนผิดที่แขนจะหลุดจากไหล่
4. **ชุดท่าทาง:** 6 ท่า (ยืน เดิน ชี้ โบกมือ ดีใจ คิด) สลับดูบนตัวละครเดียวกัน
5. **Style frame:** เลือกชุดสี + คู่ฟอนต์ แล้วเห็นเฟรมตัวอย่าง 1 เฟรมเปลี่ยนตาม

งาน: บทฉบับร่าง + ตัวละครแยกชิ้นส่วน + style frame 2 เฟรม

### สัปดาห์ 9 · Storyboard และ Animatic
**syllabus:** storyboard ฉบับสมบูรณ์ · ตัดต่อ animatic พร้อมจังหวะเสียงหรือเพลงชั่วคราว · ตรวจความคืบหน้าครั้งที่ 1

Interactive:
1. **Storyboard vs Animatic:** เทียบให้เห็นว่า animatic คือ storyboard ที่ใส่เวลาและเสียง
2. **เครื่องเล่น animatic:** ช่องภาพ 6–10 ช่อง ตั้งเวลาแต่ละช่อง กดเล่นแล้วภาพเปลี่ยนตามเวลา มีแถบเวลารวม (ใช้ตัวสร้าง storyboard จากสัปดาห์ 4 เป็นฐาน)
3. **เคาะจังหวะ:** ปุ่มเคาะตามจังหวะเพลงเพื่อหา BPM แล้วแสดงว่าควรตัดภาพทุกกี่วินาที
4. **กราฟจังหวะเรื่อง:** กราฟแท่งความยาวแต่ละช็อต เห็นช่วงที่เร็วและช้า
5. **เช็กลิสต์ตรวจความคืบหน้าครั้งที่ 1**

งาน: storyboard ฉบับสมบูรณ์ + animatic

### สัปดาห์ 10 · Character Animation และ Motion ขั้นสูง
**syllabus:** ผูกโครงตัวละคร 2 มิติ (rigging) ท่าเดินและท่าทาง · transition และ kinetic typography · ผลิตฉากหลักของงาน

Interactive:
1. **ลำดับชั้นแม่–ลูก:** แขน 3 ท่อน (ไหล่ ศอก ข้อมือ) แถบหมุนแยกแต่ละข้อ หมุนไหล่แล้วทั้งแขนตาม หมุนข้อมือแล้วขยับแค่มือ
2. **ผูกโครงตัวละคร:** ตัวละครจากสัปดาห์ 3 เปิดให้เห็นกระดูกและจุดหมุน ลากปลายมือหรือเท้าได้
3. **ท่าเดิน 4 ท่าหลัก:** contact, down, passing, up แถบเลื่อนไล่ทีละเฟรม และปุ่มเล่นวน ปรับความเร็วได้
4. **แกลเลอรี transition:** ตัวอย่าง 6 แบบระหว่าง 2 ฉาก กดเล่นทีละแบบ
5. **Kinetic typography:** พิมพ์ข้อความเอง เลือกรูปแบบการเข้า (ทีละตัวอักษร ทีละคำ เด้ง เลื่อน) ปรับความเร็วและ easing

งาน: ฉากหลัก 2–3 ฉากที่มีตัวละครเคลื่อนไหว

### สัปดาห์ 11 · Production และ Post-production
**syllabus:** แอนิเมตทั้งเรื่อง · ใส่เสียงพูด เพลง และเสียงประกอบ · ออกแบบโปสเตอร์หรือ key visual สำหรับสื่อสิ่งพิมพ์และสื่อออนไลน์ · ตรวจความคืบหน้าครั้งที่ 2

Interactive:
1. **ชั้นของเสียง:** แผนภาพ 3 แทร็ก (เสียงพูด เพลง เสียงประกอบ) แถบปรับระดับ และปุ่มเปิดปิด "ลดเสียงเพลงเมื่อมีเสียงพูด" แสดงผลเป็นกราฟระดับเสียง (ไม่จำเป็นต้องมีเสียงจริง)
2. **ตัวเลือกการส่งออก:** เลือกปลายทาง (YouTube, แนวตั้งสำหรับมือถือ, ฉายในห้อง) → แนะนำขนาดภาพ อัตราส่วน และเฟรมเรต
3. **จากเฟรมสู่โปสเตอร์:** key visual ชิ้นเดียว สลับดูใน 3 ขนาด (A3 แนวตั้ง, 1080×1350, 1920×1080) เห็นว่าต้องจัดองค์ประกอบใหม่ ไม่ใช่แค่ครอป พร้อมเปิดปิดพื้นที่ปลอดภัย
4. **สิ่งพิมพ์ vs ออนไลน์:** สรุปโหมดสี ความละเอียด ระยะตัดตก โยงกลับสัปดาห์ 1
5. **ตัวสร้างชื่อไฟล์:** กรอกรหัสนักศึกษา ชื่องาน เวอร์ชัน → ได้ชื่อไฟล์ตามรูปแบบ มีปุ่มคัดลอก
6. **เช็กลิสต์ตรวจความคืบหน้าครั้งที่ 2**

งาน: วิดีโอฉบับเกือบสมบูรณ์ + โปสเตอร์หรือ key visual ฉบับร่าง

### สัปดาห์ 12 · Final Project: นำเสนอผลงาน
**syllabus:** ส่งไฟล์วิดีโอ โปสเตอร์หรือ key visual และไฟล์งานต้นฉบับ · นำเสนอและวิพากษ์ผลงาน

โครงเดียวกับสัปดาห์ 6 ปรับเนื้อหา:
1. **เช็กลิสต์ส่งงาน 3 กลุ่ม:** วิดีโอ, โปสเตอร์หรือ key visual, ไฟล์ต้นฉบับ
2. **โครงสร้างโฟลเดอร์ส่งงาน:** แผนผังโฟลเดอร์ตัวอย่าง กดดูว่าแต่ละโฟลเดอร์ใส่อะไร
3. **โครงการนำเสนอ:** ลำดับที่แนะนำ (โจทย์ → แนวคิด → กระบวนการ → ผลงาน → สิ่งที่ได้เรียนรู้) พร้อมตัวจับเวลา
4. **ประเมินตัวเอง** และ **กรอบการวิพากษ์** (ใช้ซ้ำจากสัปดาห์ 6)
5. **สะท้อนการเรียนทั้งเทอม:** ไทม์ไลน์ 12 สัปดาห์ ติ๊กทักษะที่ได้
