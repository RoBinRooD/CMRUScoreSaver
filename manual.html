1. เข้าสู่ระบบและสมัคร (ทำครั้งเดียว)

  1. กด เข้าสู่ระบบด้วย Google แล้วเลือกบัญชีมหาวิทยาลัย รหัสนักศึกษา@g.cmru.ac.th
  2. ระบบจะแสดงชื่อและรายวิชาของคุณจากรายชื่อลงทะเบียน ตรวจว่าเป็นชื่อคุณ แล้วกด ยืนยันสมัคร (ใส่ชื่อเล่น/เบอร์โทรได้ ไม่บังคับ)
  3. ถ้าลงหลายวิชา สมัครครั้งเดียวเห็นทุกวิชา — สลับวิชาได้ที่ช่องเลือกวิชามุมขวาบน
บัญชีส่วนตัว เช่น @gmail.com จะเข้าระบบไม่ได้ · ถ้าขึ้นว่า "ยังไม่พบรายชื่อ" แปลว่ารหัสยังไม่อยู่ในรายชื่อของวิชา ให้แจ้งอาจารย์ แล้วกด ลองใหม่

2. ภาพรวม

หน้าแรกของแต่ละวิชา สรุปทุกอย่างที่ต้องรู้:

  • ส่งงานแล้วกี่งาน คะแนนงาน การเข้าเรียน และเกรด (เมื่ออาจารย์ประกาศ)
  • ต้องส่งเร็วๆ นี้ — งานที่ยังไม่ส่ง พร้อมนับถอยหลัง · แถบแดงด้านบน = มีงานเลยกำหนดที่ยังไม่ส่ง
  • งานย่อยของคุณในบอร์ดกลุ่ม · ความเห็นล่าสุดจากอาจารย์ · สรุปการเข้าเรียน

แท็บ Syllabus มีคำอธิบายรายวิชา แผนการสอน 16 สัปดาห์ เกณฑ์การให้คะแนน และไฟล์ประกอบการสอน

3. ส่งงาน

  1. แท็บ งานที่ต้องส่ง → เลือกการ์ดของงาน
  2. ลากไฟล์มาวาง หรือกด เลือกไฟล์ — ส่งได้หลายไฟล์ ไฟล์ใหญ่ได้ (รอให้แถบความคืบหน้าวิ่งถึง 100% และขึ้นว่าสำเร็จ)
  3. หรือแปะลิงก์ (ต้องขึ้นต้นด้วย https:// เช่น YouTube, Behance) แล้วกด บันทึกลิงก์
  4. สถานะเปลี่ยนเป็น ส่งแล้ว · คลิกชื่อไฟล์เพื่อเปิดดูได้ (เห็นเฉพาะคุณและอาจารย์)
  • ลบไฟล์และส่งใหม่ได้จนกว่าอาจารย์จะให้คะแนน — ตรวจแล้วแก้ไม่ได้
  • เลยกำหนด: ถ้างานนั้นรับงานช้า จะส่งได้แต่ขึ้นว่า ส่งช้า · ถ้าไม่รับ จะส่งไม่ได้
  • งานที่เลยกำหนดแล้วไม่ส่ง = 0 คะแนน

4. งานกลุ่ม

การ์ดงานที่มีป้าย งานกลุ่ม ≤ n คน ต้องอยู่ในกลุ่มก่อนจึงจะส่งงานได้

  1. คนแรกกด สร้างกลุ่ม → ตั้งชื่อกลุ่ม → ติ๊กเลือกเพื่อน (เลือกเกินจำนวนที่อาจารย์กำหนดไม่ได้ · เพื่อนที่อยู่กลุ่มอื่นแล้วเลือกไม่ได้)
  2. เพื่อนที่ถูกเลือกจะเห็นกลุ่มทันที ไม่ต้องสร้างซ้ำ
  3. ใครในกลุ่มส่งไฟล์ก็เป็นงานของทั้งกลุ่ม — ทุกคนเห็น เปิด และลบไฟล์ได้
  • แก้ไขกลุ่ม เพิ่ม/เอาเพื่อนออก · ออกจากกลุ่ม ถ้าถูกเพิ่มผิด
  • กลุ่มจะถูกล็อกเมื่ออาจารย์ให้คะแนนแล้ว หรือเลยกำหนดส่ง (งานที่ไม่รับงานช้า) — ต้องการเปลี่ยนให้ติดต่ออาจารย์
  • คะแนนให้ทั้งกลุ่ม แต่อาจารย์อาจปรับคะแนนบางคนได้

5. บอร์ดกลุ่ม (วางแผนงาน)

  1. แท็บ บอร์ดกลุ่ม → กดป้ายกลุ่มของคุณ (ป้าย กลุ่มของฉัน)
  2. กด + เพิ่ม ในคอลัมน์ ต้องทำ / กำลังทำ / เสร็จแล้ว → ใส่ชื่องาน ผู้รับผิดชอบ และวันกำหนด
  3. ย้ายการ์ดโดยลากข้ามคอลัมน์ หรือกด ← → บนการ์ด (บนมือถือใช้ปุ่มลูกศร) · กดที่การ์ดเพื่อแก้ไขหรือลบ

แผนงานเห็นเฉพาะสมาชิกในกลุ่มและอาจารย์ · กลุ่มอื่นเห็นแค่ชื่อกลุ่มและสมาชิก · งานย่อยที่มีวันกำหนดจะขึ้นใน Timeline และหน้าภาพรวม

6. Timeline

แถบของแต่ละงาน เริ่มจากวันที่อาจารย์สั่งงานถึงกำหนดส่ง สีบอกสถานะของคุณ (ตรวจแล้ว / ส่งแล้ว / ส่งช้า / ไม่ได้ส่ง / ยังไม่ส่ง) มีเส้น วันนี้ · ชี้ที่แถบเพื่อดูรายละเอียด · กด รายการ เพื่อดูเป็นตาราง · งานย่อยจากบอร์ดกลุ่มแสดงด้านล่าง

7. ส่งใบลา

  1. แท็บ ใบลา → + ส่งใบลา
  2. เลือกสัปดาห์ที่ลา (นับตามสัปดาห์เรียนของวิชา 1–16) วันที่ ประเภท (ลาป่วย / ลากิจ / อื่นๆ) และเหตุผล
  3. แนบหลักฐานได้ เช่น ใบรับรองแพทย์ (รูปหรือ PDF ไม่เกิน 5 ไฟล์ ไฟล์ละ 20 MB) → ส่งใบลา
  • สถานะ รออนุมัติ → อนุมัติ หรือ ไม่อนุมัติ พร้อมความเห็นของอาจารย์
  • อนุมัติแล้ว การเช็คชื่อสัปดาห์นั้นจะเป็น E (ลา) อัตโนมัติ · ลาไม่นับเป็นขาด
  • ส่งได้ทั้งก่อนและหลังวันที่ลา · ยกเลิกได้ระหว่างรออนุมัติ · 1 ใบ = 1 สัปดาห์

8. คะแนนและการเข้าเรียน

แท็บ คะแนนของฉัน: คะแนนแต่ละงานพร้อมความเห็น คะแนนสอบ และการเข้าเรียน 16 สัปดาห์ (P = มา · L = สาย · E = ลา · A = ขาด · · = ยังไม่เช็ค)

เกณฑ์การขาดเรียน (อาจารย์อาจปรับได้ — ดูตัวเลขจริงในหน้าคะแนนของคุณ)
  • ขาดที่นับ = ขาด + สายทุก 2 ครั้งนับเป็นขาด 1 ครั้ง · ลาไม่นับ
  • ขาดที่นับตั้งแต่ 3 ครั้ง อาจารย์จะติดตาม · ขาดเกิน 4 ครั้ง = เกรด F

คะแนนรวมและเกรดจะแสดงเมื่ออาจารย์ประกาศ

นำเข้าไฟล์รายชื่อซ้ำได้ทุกเมื่อ (เช่น มีคนเพิ่ม/ถอน) — ระบบอัปเดตชื่อและเพิ่มคนใหม่ ไม่ลบคะแนนหรือบัญชีที่สมัครไว้ · คนที่ไม่อยู่ในไฟล์ใหม่จะขึ้นเตือนให้ตรวจ

2. ภาพรวม

  • สมัครแล้ว x/y · งานที่เปิด · รอตรวจ (กดไปตรวจได้เลย) · เข้าเรียนเฉลี่ย · แถบเตือนใบลารออนุมัติ
  • ความคืบหน้าแต่ละงาน: ตรวจแล้ว / ส่งแล้วรอตรวจ / ยังไม่ส่ง + ปุ่ม ตรวจ n
  • นักศึกษาที่ควรติดตาม: ขาดเรียน (นับ) ตั้งแต่ 3 ครั้ง ขาดส่งตั้งแต่ 2 งาน หรือเข้าเรียนต่ำกว่า 80% — คนที่ขาดเกินเกณฑ์ (F) ขึ้นบนสุด
  • การกระจายเกรดคาดการณ์จากคะแนนที่มีตอนนี้

3. สร้างงาน

แท็บ งาน → + สร้างงาน

คะแนนเต็ม / กำหนดส่งคะแนนเต็มของงานนี้ (ระบบแปลงเป็นสัดส่วนให้เอง)
นับเป็นคะแนนคะแนนเก็บครึ่งเทอมแรก หรือ ครึ่งเทอมหลัง — ใช้แยก 2 ช่องของระบบทะเบียน
รับงานหลังกำหนดติ๊ก = ส่งช้าได้แต่ขึ้นว่าส่งช้า · ไม่ติ๊ก = เลยกำหนดแล้วส่งไม่ได้
แสดงให้นักศึกษาเห็นไม่ติ๊ก = ซ่อนไว้ก่อน (ไม่นับคะแนน)
งานกลุ่มติ๊ก + จำนวนสมาชิกสูงสุด · นักศึกษาจับกลุ่มเอง · เปลี่ยนเดี่ยว↔กลุ่มไม่ได้หลังมีคนส่ง/จับกลุ่มแล้ว

งานที่มีคนส่งแล้วลบไม่ได้ — ใช้ "ซ่อน" แทน · ไฟล์งานอยู่ใน Drive ของอาจารย์ที่ CMRUScoreSaver งานนักศึกษา/รหัสวิชา/งาน/รหัส ชื่อ

4. ตรวจงาน

  1. แท็บ ตรวจงาน → เลือกงาน → กรอง "ส่งแล้ว ยังไม่ตรวจ"
  2. คลิกชื่อไฟล์เพื่อเปิดใน Drive → ใส่คะแนนและความเห็น (แถวที่แก้จะเป็นสีเหลือง) → บันทึกคะแนน
หน้าตรวจงานต้องกด "บันทึกคะแนน" (ต่างจากหน้าเช็คชื่อที่บันทึกอัตโนมัติ)

งานกลุ่ม

  • ตารางแบ่งตามกลุ่ม · ใส่คะแนน/ความเห็นในแถวกลุ่ม = เติมให้สมาชิกทุกคน แล้วปรับรายคนได้
  • แก้กลุ่ม / + สร้างกลุ่ม — อาจารย์ย้ายคนข้ามกลุ่มได้และเกินจำนวนที่กำหนดได้ · นักศึกษาที่ยังไม่มีกลุ่มอยู่ท้ายตาราง
  • ให้คะแนนแล้ว กลุ่มนั้นถูกล็อก นักศึกษาแก้กลุ่ม/ส่งเพิ่มไม่ได้

5. เช็คชื่อ

  1. แท็บ เช็คชื่อ → กดเลขสัปดาห์ที่หัวตาราง = ทุกคนที่ยังว่างเป็น "มา"
  2. คลิกช่องของคนที่สาย/ขาด/ลา เพื่อเปลี่ยน: ว่าง → P (มา) → L (สาย) → A (ขาด) → E (ลา) → ว่าง
  3. บันทึกอัตโนมัติ — ดูป้ายมุมขวาบน: ● รอบันทึก → ✓ บันทึกแล้ว
  • ทุกคลิกเก็บสำรองในเครื่องทันที ถ้าเน็ตหลุด ป้ายจะเป็นสีแดงและระบบลองส่งใหม่เอง · ช่องที่ยังไม่ยืนยันมีจุดสีส้ม
  • ปิดหน้าไปก่อนบันทึก → เปิดหน้าเช็คชื่อใหม่ด้วยเครื่องและเบราว์เซอร์เดิม ระบบจะกู้คืนและส่งให้ (สำรองเก่ากว่า 6 ชั่วโมงจะถามก่อนว่า ส่ง / ทิ้ง)
  • คอลัมน์ท้ายตาราง ขาด (นับ) อัปเดตทันที: สีส้ม = ต้องติดตาม · แดง "· F" = เกินเกณฑ์
ช่องว่าง = ยังไม่เช็ค ไม่นับ — คนที่ขาดต้องกดเป็น A ทุกครั้ง · ขาดที่นับ = A + สายทุก 2 ครั้ง · ลาไม่นับ · ขาดเกิน 4 ครั้ง = F (ปรับได้ที่แท็บตั้งค่า)

6. ใบลา

  1. แท็บ ใบลา (ภาพรวมและหน้าเช็คชื่อจะเตือนเมื่อมีใบรออนุมัติ) → พิจารณา
  2. อ่านเหตุผลและไฟล์แนบ → เขียนความเห็น (ไม่บังคับ) → อนุมัติ หรือ ไม่อนุมัติ
  • อนุมัติ = สัปดาห์นั้นเป็น E (ลา) อัตโนมัติ (ถ้าเช็คว่า "มา" ไว้แล้วจะไม่เปลี่ยน)
  • เปลี่ยนใจภายหลังได้ (แก้ไข) — เปลี่ยนจากอนุมัติเป็นไม่อนุมัติ ระบบคืนค่าการเช็คชื่อเดิม

7. คะแนนสอบ

แท็บ สอบ → ตั้งคะแนนเต็มกลางภาค/ปลายภาค ตามข้อสอบจริง → กรอกคะแนน → บันทึกคะแนนสอบ · ระบบแปลงเป็นสัดส่วน (เช่น เต็ม 10) ในสมุดคะแนนให้เอง

8. สมุดคะแนนและระบบทะเบียน

  • ตารางแสดงคะแนนทุกงาน และ 4 ช่องของระบบทะเบียน: เก็บครึ่งแรก · เก็บครึ่งหลัง · กลางภาค · ปลายภาค รวม และเกรด
  • เก็บแต่ละครึ่ง = คะแนนเข้าเรียน ÷ 2 + คะแนนงานของครึ่งนั้น · รวม = ผลรวม 4 ช่อง (ตรงกับที่ระบบทะเบียนคำนวณ)
  • ติ๊ก ประกาศคะแนนรวมและเกรดให้นักศึกษาเห็น เมื่อพร้อม → บันทึกการตั้งค่า

กรอกคะแนนเข้าระบบทะเบียน

  1. กด คัดลอกสำหรับระบบทะเบียน — ตรวจว่า "คะแนนเต็มตามน้ำหนักวิชานี้" เป็น 40 / 40 / 10 / 10 ตรงกับที่ตั้งในระบบทะเบียน
  2. กด คัดลอก แล้ววางในช่องนำเข้าคะแนนของระบบทะเบียน (รหัสละบรรทัด คั่นด้วยแท็บ ไม่มีหัวตาราง)
นักศึกษาที่ขาดเรียนเกินเกณฑ์ ระบบทะเบียนจะคิดเกรดจากคะแนน — หน้าต่างคัดลอกจะแสดงรายชื่อที่ต้องแก้เป็น F เองในระบบทะเบียน · ค่าเริ่มต้นปัดเป็นจำนวนเต็ม (รวมอาจต่างจากในเว็บ ±2) ถ้าระบบทะเบียนรับทศนิยมได้ ให้เอาติ๊กออก

ดาวน์โหลด Excel เก็บสำรองได้ทุกเมื่อ (มีคะแนนทุกงาน ขาดเรียน และหมายเหตุ)

9. จัดการนักศึกษา

  • + เพิ่มนักศึกษา — คนที่ลงทะเบียนช้า/ไม่อยู่ในไฟล์
  • แก้/รีเซ็ต — เปลี่ยนบัญชีที่ผูกไว้ (เว้นว่าง = ให้นักศึกษาสมัครใหม่) หรือกำหนดอีเมลให้เอง
  • กรอง "ยังไม่สมัคร" เพื่อตามคนที่ยังไม่เข้าระบบ

อีเมลอาจารย์เพิ่มผู้ช่วยสอนได้ บรรทัดละ 1 อีเมล
โดเมนอีเมลcmru.ac.th (รับ g.cmru.ac.th ด้วย) — ห้ามว่าง (นักศึกษาจะเข้าไม่ได้) · ห้ามใส่ gmail.com ตอนใช้งานจริง
ขนาดไฟล์สูงสุดต่อไฟล์ที่นักศึกษาส่ง (MB)
เกณฑ์เกรดคะแนนรวมขั้นต่ำของแต่ละเกรด

เกณฑ์การขาดเรียนขาดเกิน n = F · ขาดตั้งแต่ n = ติดตาม · สาย n = ขาด 1

ลบวิชา

  1. ตั้ง PIN สำหรับลบข้อมูล ก่อน (ตัวเลข 4–8 หลัก · ลืม PIN: ลบค่า deletePinHash ในแท็บ Settings ของ Google Sheet แล้วตั้งใหม่)
  2. เลือกวิชาที่จะลบที่มุมขวาบน → การ์ดสีแดง ลบวิชา → ตรวจรายการที่จะถูกลบ → ใส่ PIN → ลบถาวร
ลบแล้วกู้ไม่ได้ — ดาวน์โหลด Excel เก็บไว้ก่อน · ติ๊ก "ย้ายไฟล์งานไปถังขยะ" ได้ถ้าต้องการ (กู้จากถังขยะ Drive ได้ 30 วัน) · ใส่ PIN ผิด 5 ครั้งล็อก 1 ชั่วโมง

12. เมื่ออัปเดตระบบ

  1. วาง dist/Code.gs ใหม่ทับใน Apps Script → 💾
  2. ถ้าการอัปเดตแจ้งว่ามีคอลัมน์/แท็บใหม่: เลือก setup → ▷ เรียกใช้ (ไม่ลบข้อมูล)
  3. การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้ (URL เดิม ไม่ต้องแก้ config)
